A Dictionary of Agentic Coding

The vocabulary of running agents on real codebases, one term per entry.

Matt Pocock’s AI Coding Dictionary covers the primitives: tokens, context windows, tool calls, handoffs. This dictionary starts where that one stops. Its terms name what accumulates when agents write most of the code, where their output diverges from intent, the rules that keep it honest, and the written record that carries knowledge between sessions.

Each entry defines the term, names the symptom you have probably already hit, and says what to do. Click any term in the map to read it; entries link on first mention.
